- **CWE:** CWE-347
- Replaced verify_signature=False with full HS256 verification; removed 'none' algorithm

- **Fix:** subprocess([...], shell=False) + host regex validation
- **CWE:** CWE-78
- Replaced shell=True f-string with safe list-form subprocess + regex whitelist
